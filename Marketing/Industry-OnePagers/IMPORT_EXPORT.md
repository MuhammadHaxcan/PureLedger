## How PureLedger Solves These

### Multi-Project Architecture
Treat each import shipment or product line as a separate project with its own books.

```
Project: Container ABC-2024-001
├── Categories: Customers, Suppliers, Products
├── Accounts: Specific to this shipment
└── Reporting: Isolated P&L and balance
```

- Separate ledgers per import lot
- Consolidated reporting when needed
- True cost visibility by shipment

### Integrated Documentation
Delivery challans and invoices created from the same transaction.

| Document | Creation |
|----------|----------|
| Sale Voucher | Original transaction record |
| Delivery Challan | Processed from voucher |
| Invoice | Based on voucher data |
| Shipping Reference | Captured in DC fields |

### Comprehensive Cost Tracking
All costs captured and allocated to the right accounts.

| Cost Type | PureLedger Feature |
|-----------|-------------------|
| International freight | FOR charges system |
| Local cartage | Cartage processing |
| Handling charges | Journal entries with references |
| Customer allocation | Auto-posting to customer accounts |

### Advanced Aging Analysis
Track receivables with awareness of credit terms and creditable dates.

- Transaction date vs. creditable date distinction
- Aging buckets based on actual payment due dates
- Customer-level balance visibility
- Project-filtered aging for specific shipments

### Flexible Reporting
Multiple report types for different stakeholder needs.

| Report | Stakeholder | Use Case |
|--------|-------------|----------|
| Master Report | Finance | Complete ledger view |
| Account Report | Credit Manager | Customer-specific transactions |
| Product Report | Operations | Inventory and margin analysis |
| Aging Report | Collections | Overdue accounts |
| User Report | Sales Team | Their assigned accounts only |
