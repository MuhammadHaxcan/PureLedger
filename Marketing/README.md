# PureLedger Marketing Collateral Library

## Overview

This directory contains all marketing collateral for PureLedger's international marketing execution plan. Materials are organized by type and purpose, supporting Phase 1 target markets (Pakistan, UAE, Saudi Arabia, Bangladesh, India).

## Usage Guidelines

### For Marketing Team
1. Use Brand Guidelines for all visual and voice decisions
2. Update documents as product evolves
3. Track which collateral performs best in campaigns

### For Sales Team
1. Start with Demo Script for standard demos
2. Use Industry One-Pagers for vertical-specific prospects
3. Reference Objection Handling during calls
4. Customize Pricing Sheet for proposals

### For Partners
1. Share Product Brochure for partner education
2. Use Feature Comparison for competitive situations
3. Provide ROI Calculator for value discussions

## Key Differentiators to Emphasize

In all materials, consistently highlight:

1. **Native DC Integration** - Not an add-on
2. **Automatic FOR/Cartage** - Freight allocation built-in
3. **Base Voucher System** - Standing order management
4. **Trading-Specific Reports** - Built for trading workflows
5. **Granular Permissions** - Project/category/action level control
6. **Regional Fit** - Understanding of South Asian/Middle East markets
